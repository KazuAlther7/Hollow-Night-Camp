## About the Project

**Hollow Night Camp** is the official website for the *Hollow Night* fictional universe and its community. Designed around a mysterious, atmospheric experience, the site brings story content and investigation tools together in one place.

From exploring the novels to examining theories and hidden clues, visitors are invited to step into the mystery and become part of the investigation.

## Features

- **Story & Novel Library** — Explore the available *Hollow Night* stories and reading content.
- **Investigation & Theories** — Follow ideas, connect clues, and explore possible explanations behind the mysteries.
- **Arcade** — Visit the site's arcade area for interactive entertainment.
- **Author Tools** — A dedicated editing experience is part of the site's development, intended to make managing story content easier.
- **Reader Accounts** — Account and profile functionality is being developed to support a more personalized experience.
- **Atmospheric Interface** — A dark, mystery-inspired visual direction designed to support the identity of *Hollow Night*.
- **Responsive Layout** — Built for a comfortable experience across desktop and mobile screens.

> **Development note:** Hollow Night Camp is an evolving project. Feature availability and behavior may change as development continues.

## Technology

The project is built as a web-based experience using:

- **HTML5** — Page structure and content.
- **CSS3** — Layout, visual styling, and responsive presentation.
- **JavaScript** — Interactive behavior and client-side functionality.
- **Supabase** — Backend services for supported account and database features.

The repository is organized into page files and supporting asset, style, script, and configuration directories.

## Getting Started

You can explore the live website directly:

**[kazualther7.github.io/Hollow-Night-Camp](https://kazualther7.github.io/Hollow-Night-Camp/)**

To inspect or work on the source code locally:

1. Clone the repository.

   ```bash
   git clone https://github.com/KazuAlther7/Hollow-Night-Camp.git
   ```

2. Open the project folder.

   ```bash
   cd Hollow-Night-Camp
   ```

3. Open `index.html` in your browser, or run the project through a local development server if your changes or backend configuration require one.

4. If working with backend-powered features, use the project's intended Supabase configuration. **Never commit private keys, service-role keys, passwords, or other secrets to the repository.**

## Development & Contributions

Hollow Night Camp is an independently developed project. Suggestions, bug reports, and ideas that help improve the website are welcome.

Before submitting a report, please:

1. Check whether the issue has already been reported.
2. Describe what you expected to happen and what happened instead.
3. Include clear reproduction steps and screenshots when useful.
4. Avoid sharing passwords, access tokens, private user data, or other sensitive information.

Use the [GitHub Issues page](https://github.com/KazuAlther7/Hollow-Night-Camp/issues) to report a problem or suggest an improvement.

## Security

Please do not publish credentials or private configuration values in issues, commits, screenshots, or discussions. Backend access should be protected by appropriate authentication, database permissions, and Row Level Security (RLS) policies.

If you discover a security concern, avoid posting exploitable details publicly. Contact the project maintainer through an appropriate private channel where available.
